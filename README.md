# Gestión de Hojas de Actividad de Prácticas

## Descripción

Este proyecto consiste en una aplicación web que permite a los estudiantes gestionar sus hojas de actividad de prácticas.

La aplicación facilita la creación de una hoja de prácticas, el registro semanal de las tareas realizadas durante el periodo de prácticas y la generación del documento final en formato Word para su descarga.

---

## Funcionalidades

- Inicio de sesión mediante DNI y contraseña.
- Creación de una hoja de actividad de prácticas.
- Registro de las tareas realizadas cada semana.
- Edición de las actividades registradas.
- Visualización de todas las semanas cumplimentadas.
- Generación y descarga de la hoja de actividades en formato Word (.docx).
